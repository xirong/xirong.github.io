## 1. 这个系列要做成什么样

- **读者**：柳智天，快 6 岁。所有讲解都要短句、口语、能听懂，但**不能为了好懂讲错**。
- **一句话目标**：用真实照片做出的 3D 星球，孩子拖一拖、点一点，就能学到这颗星球“长什么样、里面是什么、有多大、怎么动、会发生什么、和我们的关系、一生的故事、谁去研究过”。
- **逼真优先**：星球表面、云、夜灯、卫星照片都用**真实影像**（NASA 等公有领域）。代码只负责光照、动画、交互（见根目录 `CLAUDE.md`“真实纹理优先”）。
- **科学正确优先于好看**：旋转方向、大小比例、时间顺序、因果关系都必须符合真实世界。做不到真实比例的地方，场景里要写明“不是真实比例”。

## 3. 地球页审查发现的问题（木星最容易重犯的就是这些）

下面每条都是真实发生过的错误。“规则”是从中总结出来的，做木星时逐条对照。

### 3.1 旋转方向（最常见、最隐蔽）

| 错误 | 正确 |
|---|---|
| 地球公转、月球公转画成了顺时针 | 从北极上方往下看，行星公转、自转、大多数卫星公转都是**逆时针** |
| 点“转一天”时地球反着转（太阳从西边升起） | 自西向东转 |
| 台风顺时针转（旁边配的真实照片却是逆时针） | 北半球气旋逆时针、南半球顺时针；**反气旋相反** |
| 月球潮汐锁定，但朝着地球的是侧面 | 贴图正面（经度 0°）要一直对着母星 |

**规则**：
- Three.js 里 `rotation.y` 增大 = 从 +y（北）往下看逆时针。位置写成 `(cos a, 0, sin a)` 时，**a 增大是顺时针**，要逆时针就让 a 减小，或者写成 `(cos a, 0, -sin a)`。每个转动的地方都加一行注释写清方向，然后**截两张图对比确认**。
- `SphereGeometry` 的 uv：`u = 0.5` 在局部 +x，经度 -180° 在 u = 0。经纬度换算用地球页的 `lonLat(lon, lat, r)`。
- 物体朝向母星：位置角为 a 时，`rotation.y = -a - π` 才能让贴图中心对着原点（推导写在地球页 `motion_moon` 注释里）。

### 3.2 大小比例与透视

| 错误 | 正确 |
|---|---|
| “4 个月球刚好排满地球直径”，月球还比地球边缘多出一截 | 真实比值约 3.7。画面按真实比例排，文字说“3 个多一点” |
| 月球放在地球前面（离镜头更近），透视让它们显得更大 | 比大小的东西必须**放在离镜头一样远的平面上**，并排比 |
| 阿波罗场景里月球比地球大一倍多 | 地球直径是月球的 3.7 倍 |
| 天平上月球按“等质量”缩小，和别处大小不一致 | 同一个物体全页用同一个真实比例 |
| 地壳画成占半径 18%，文字却说“最薄” | 地壳不到 1%，画成细细一圈（可略加粗，并注明） |

**规则**：所有“比大小”的场景，比例常数集中定义一次（如 `MOON_D = 0.2727`），全页共用；数值和画面必须一致；做不到真实比例的，用 `api.live()` 写明“距离/大小压缩了”。

### 3.3 画面、文字、按钮必须一致

| 错误 | 正确 |
|---|---|
| “10 份里 7 份是海洋”，画面却 10 杯全是蓝色 | 7 蓝 3 陆 |
| 标题、按钮、旁白都说“看月食”，画面是开船 | 讲什么就演什么；两件事就给两个按钮 |
| 10 个场景的提示“点‘震一下’”，按钮其实叫“模拟地震” | 提示里的按钮名**逐字复制** `earth-data.js` 里的 `label` |
| “家长看”写“用了法线贴图”，代码没用 | 家长说明只写真做了的事 |
| 星云场景旁白讲地球聚积，画面是太阳诞生 | 画面主角 = 旁白主角 |

### 3.4 科学说法

| 错误 | 正确 |
|---|---|
| “小生命变成鱼、变成恐龙……才出现人类”（暗示人是恐龙变的），时间说“好多好多万年” | “先后出现了鱼、恐龙，人类是最近几十万年才有的”；最早的生命约 35 亿年前 |
| 远古地球直接显示今天的大陆，还马上变绿 | 早期几乎全是海；陆地植物比海洋生命晚 30 多亿年；大陆一直在漂移 |
| “麦哲伦绕一圈回到起点” | 麦哲伦 1521 年死在菲律宾，是剩下的船员回去的 |
| 内核“比太阳表面还热”“冻成了硬块” | “和太阳表面差不多热”；“压力太大，铁熔化不了，所以是固体” |
| 大碰撞形成月球说成定论 | 假说要加“科学家认为” |
| 地震：两块板块互相穿透；火山：整座山里面都是岩浆 | 地震 = 卡住 → 拧弯 → 突然滑开；火山 = 固体山体 + 细通道 + 地下岩浆房 |
| 从太空看整个地球边缘变成晚霞 | 晚霞要站在地面上看；从太空只在晨昏线附近有橙红色 |

**规则**：每个数字都要能在 NASA 资料里查到（见第 5 节链接）；假说加“科学家认为”；说演化、形成时讲“先后出现”，不讲“变成”；比喻不能制造误解。

### 3.5 逼真度

| 问题 | 怎么改的 |
|---|---|
| 地表、夜灯、云只有 2048 像素，凑近一片模糊 | 换 NASA 原图：Blue Marble 21600 像素、Black Marble 夜灯、NASA 云图 8192 像素，处理成电脑 8K、手机 4K |
| 山脉没有立体感 | 用 GEBCO 高程算法线贴图，shader 里按球面切线方向（东、北）扰动法线 |
| 大气只有一圈均匀的蓝边 | 晨昏线附近地面和云染橙红；大气边缘白天蓝、晨昏橙、背光一侧几乎没有 |
| 云层离地 90 公里，没有云影 | 降到约 25 公里；地表 shader 按云层的经度偏移取云图做影子 |
| 台风是一团白点；陆地是三个圆锥 | 改成**在高清主星球上**贴真实卫星俯拍图、按真实经纬度飞过去看 |
| 斜拍的照片当俯视贴图 | 贴到球面上的图必须是正上方拍的（地球页换成了 NASA MODIS 俯拍的台风） |

**规则**：能用主星球的真实贴图演示，就不要另造玩具模型；需要贴到球上的照片必须是正射或俯拍；海面反光、夜灯等只出现在该出现的地方（用遮罩）。

### 3.6 渲染上的坑

- **辉光（bloom）阈值约 0.86**：亮度超过它的东西会被糊成一团白，比如白色帆、太亮的岩浆、太大的反光。颜色压到 0.85 以下，或减弱自发光。
- **Sprite 标签**用 `sizeAttenuation: false`，默认 `depthTest: false` 会穿过星球显示在背面。贴在会转到背面的地方时，改成 `depthTest = true`。
- 挂到父物体上会被父物体缩放放大，要 `label.scale.divideScalar(父缩放)`。
- 场景卡片在左边（手机在下边），`stage.js` 会自动把画面中心往右/往上挪。所以镜头要留余量，**每个场景都要在桌面和手机两种尺寸下截图确认主体没被卡片挡住**。
- 长卡片不能靠压缩文字塞下：直接子项用 `flex: 0 0 auto`，让 `overflow-y: auto` 真正滚动；切换知识点时把卡片 `scrollTop` 归零。否则手机上会出现文字、滑块和按钮互相叠住。
- 半透明的“剖面”被前面的球挡住时，把球改成 `side: THREE.BackSide`，只画后半个球壳。
- 挂到 `surface` 上的东西不会被 `api.root` 自动清理，必须在 `exit()` 里摘掉。

## 4. 我是怎么检查的（做完请按同样流程自测）

1. **先读数据和旁白**：逐条对照 NASA 资料核数字；找“画面 ↔ 文字 ↔ 按钮”对不上的地方。
2. **再读每个场景函数**：重点看转动方向（正负号）、位置公式、比例常数、`live()` 文字和画面是否一致、有没有物体互相穿透、有没有挂到 `surface` 上忘了摘。
3. **打开页面实际看**。启动方式：仓库根目录 `.claude/launch.json` 的 `static-site`（`python3 -m http.server 8765`），然后打开 `http://localhost:8765/space/jupiter-3d/index.html`。在浏览器控制台里用这个小工具逐个场景截图：

   ```js
   window.visit = async (m, i, act, wait = 7000) => {
     __explorer.go(m);
     document.querySelector(`#stage-${m} .stage-step[data-i="${i}"]`).click();
     await new Promise(r => setTimeout(r, 2500));
     if (act != null) document.querySelectorAll(`#stage-${m} .stage-action`)[act]?.click();
     await new Promise(r => setTimeout(r, wait));
     return document.querySelector(`#stage-${m} .stage-live`).textContent;
   };
   await visit('motion', 1, 0, 5000);   // 然后截图
   ```

   - “钻进去”的每一站：`document.querySelector('.depth-stop[data-i="3"]').click()`。
   - 改了文件要 `location.reload()`，只改 `#hash` 不会重新加载。
   - 浏览器面板在后台时帧率很低，动画要多等几秒。
4. **每个场景至少截两张**：按动手按钮前一张、动作进行中或完成后一张；手机尺寸（375×812）再抽查。控制台必须零报错。
5. **语法检查**：`node --check` 每个 js；Python 脚本 `python3 -m py_compile`。
6. **提交**：按批次提交（纠错、贴图、场景），提交说明写清改了什么。推送如果 22 端口被挡，用 443：

## 5. 木星：内容方案（请按这个做，数字以 NASA 最新资料为准）

资料来源（每个数字都去核对）：
- NASA 木星事实页：https://science.nasa.gov/jupiter/facts/
- NASA 行星数据表：https://nssdc.gsfc.nasa.gov/planetary/factsheet/jupiterfact.html
- NASA Juno 任务：https://science.nasa.gov/mission/juno/

### 5.1 必须注意的木星“坑”

- **自转最快**：一天约 9 小时 56 分，所以木星明显**扁**（两极半径比赤道小约 6.5%）。球体要 `scale.y ≈ 0.935`，不能画成正圆。
- **自转和公转都是逆时针**（从北极上方看）。地轴只歪约 3°，所以**几乎没有四季**。别照抄地球的四季场景。
- **大红斑在南半球（约南纬 22°），是反气旋**：南半球的反气旋从上往下看是**逆时针**转。它在缩小：现在约 1.3 个地球宽，以前有 2～3 个地球宽。
- **条纹**：浅色的“带”（zone）是上升的气流，深色的“带”（belt）是下沉的气流。相邻的条纹风向相反，赤道附近的风很快。动画可以让不同纬度的条纹速度略有不同（参考太阳页的较差自转写法），但方向要对。
- **没有可以站的表面**：越往下越稠，气体慢慢变成液体，没有清楚的“地面”。“钻进去”时不要画出地壳。
- **木星不是“失败的恒星”**：要再重约 80 倍才可能点燃核聚变。可以讲“它还远远不够重”，不要说“差一点变成太阳”。
- **环很暗**：主要是尘埃，和土星那种亮环完全不同，只能画成淡淡的细环。
- **伽利略卫星**（木卫一 Io、木卫二 Europa、木卫三 Ganymede、木卫四 Callisto）：1610 年伽利略发现。全都逆时针公转、潮汐锁定。公转周期分别约 1.77、3.55、7.15、16.7 天，前三个是 1:2:4 的共振。木卫三是太阳系最大的卫星，比水星还大；木卫一火山最多；木卫二冰层下可能有海洋（要说“科学家认为”）。卫星总数近百颗，一直在新发现，**写数字前查 NASA 最新值**，或者只说“近百颗”。
- **极光**：在两极，主要是紫外光，要用哈勃或 Juno 的真实图。

### 5.2 “长什么样”（外观）

- **贴图**：优先用 Hubble OPAL 项目的木星全球展开图（每年一张，公有领域）或 Cassini 2000 年的全球拼图（NASA/JPL/SSI，PIA07782 一类）。网站已有的 `textures/jupiter.jpg` 只有 2048 像素，只能当兜底。写 `tools/build-textures.py` 处理成 8K/4K。
- **按钮建议**：普通看 / 大红斑凑近（飞到南纬 22°）/ 转一天（10 小时）/ 看条纹的风（不同纬度速度不同）/ “为什么是扁的？”。
- **光照**：木星离太阳远，阳光弱，但画面不要太暗；边缘有临边昏暗；没有夜灯。

### 5.3 “里面是什么”（钻进去，近似分层，都要注明“科学模型示意”）

| 站 | 大约位置 | 温度（代表值） | 讲什么 |
|---|---|---|---|
| 太空 | 用 0.1 bar 上层大气代表值 | 约零下 161℃ | 离太阳很远，很冷；真空本身没有“气温”，不要写 -230℃ |
| 云顶 | 1 个大气压处 | 约零下 110℃ | 氨冰云组成条纹，我们看到的“表面”其实是云 |
| 更深的大气 | 往下几百公里 | 越来越热 | 水云，有闪电（Juno 观测到） |
| 液态氢 | 约 0.9～0.8 R | 几千℃ | 气体被压成液体，没有分界“地面” |
| 金属氢 | 约 0.8 R 以内 | 一万多℃ | 压力大到氢能导电，产生超强磁场 |
| 核心 | 中心 | NASA 估计可达约 2 万多℃ | Juno 发现核心是“稀稀的、模糊的”，不是一个硬球 |

边界和温度各模型不一致，`dive.js` 的停靠点按上表写，家长看里注明“近似”。剖面花纹可以用：大气 = 对流（pattern 1），金属氢 = 液态流动（pattern 4），核心 = 素色（pattern 0）。

### 5.4 六个场景模块（每个 3～5 个知识点，共约 24 个）

**有多大多重**
- 11 个地球排满木星的赤道直径：按真实比例并排，放在同一深度。
- 体积约 1,300 个地球。
- 质量约 318 个地球，是其他所有行星加起来的 2.5 倍。
- 体重：比较秤的读数，不是质量变了。按 NASA 数据，1 bar 赤道视重是地球的 23.12 / 9.78 ≈ 2.364 倍；平均重力比约 2.64 含不同纬度且未计自转，不要笼统写成 2.5 倍（说明“没有地方站”）。
- 阳光到木星约 43 分钟（距离变化时约 33～53 分钟），日地距离的约 5.2 倍。

**怎么动**
- 一天不到 10 小时（自转最快），所以变扁。
- 一年约 11.9 个地球年。
- 地轴几乎不歪，所以几乎没有四季（和地球对比）。
- 伽利略卫星公转：1:2:4 共振，潮汐锁定，逆时针。

**会发生什么**
- 大红斑：南半球的反气旋，逆时针转，在缩小。用真实照片，网站已有 `textures/great-red-spot.jpg`，先确认来源。
- 条纹和风：带和带风向相反。
- 极光：在两极，用哈勃或 Juno 的真实紫外图。
- 1994 年苏梅克-列维 9 号彗星撞木星：哈勃的真实照片。
- 闪电：Juno 观测到。

**和我们的关系**
- 木星的引力会改变一些小天体的轨道。有人说它“保护地球”，科学家还在讨论，要按讨论中讲。
- 夜空里能用肉眼看到木星（很亮的“星星”），配真实的星空位置图。
- 用望远镜能看到 4 颗伽利略卫星，配真实的天文爱好者照片或 NASA 图。
- 木卫二冰下海洋：科学家在找生命的可能。

**一生的故事**
- 约 46 亿年前，木星可能是最早形成的行星（假说，加“科学家认为”）。
- 先长成岩石冰核，再吸进大量气体。
- 可能在太阳系里“搬过家”（大迁移假说，要标明是假说，也可以不讲）。
- 未来：一直这样转下去；太阳变成红巨星时，木星离得远，能保留下来（科学家估计）。

**谁去研究过**
- 1610 年伽利略用望远镜发现 4 颗卫星。
- 先驱者 10 号（1973）和旅行者 1、2 号（1979）飞过；旅行者发现了木星的环。
- 伽利略号（1995～2003）环绕木星，并往大气里放了探测器。
- 朱诺号（2016 年至今）：极地轨道，发现了“模糊的核心”、极区气旋群，拍了 JunoCam 照片。
- 正在路上的：欧空局的 JUICE（2023 年发射）、NASA 的欧罗巴快船（2024 年发射）。中国的天问四号计划去木星系，写之前**先查最新进展**。
